## 你买的100M，到底是哪种100M

大带宽租用里最容易吃亏的地方，是"100M"这三个字没写清楚。有的整机套餐在带宽一栏写的是“300Mbps微享峰值”这样的字样，“峰值”意味着短时间能冲到这个数，不代表高峰时段持续可用。真正决定业务体验的是**保底带宽**：不管几点、不管机房多忙，你随时能跑满的那部分。

下单前让对方在工单或合同里写清三件事：

1. 保底带宽的具体数值
2. 独享还是共享，共享的话同一上联还有哪些用户
3. 超出套餐后是限速、照量计费还是直接断网

## 线路怎么选：单线、多线和BGP的价差摆在这里

线路类型对价格的影响，从公开报价看非常直观：同样100M，电信单线一年15000元，双线30000元，三线40000元，BGP直接到120000元。

选法可以简单点：

- 用户基本集中在一个运营商（企业专线、定向推送、内网同步）→ 单线，省下的钱拿去加带宽
- 电信、联通用户都不少 → 双线起步
- 全国混合流量、对延迟敏感（游戏服、直播、实时交互）→ BGP，为路由调度能力付费
- 用户在海外或依赖国际出口 → 看香港、洛杉矶这类节点。比如多线通的10Gbps方案，上行从1x10GE到2x40GE可选，不限流量、固定费率，官方称最快1小时内启用，适合视频串流、游戏、物联网这类持续吃流量的业务

国内方案按带宽计费，海外方案常见“按端口速率包流量”的玩法，两种账要分开算。带宽翻倍价格不一定翻倍，但线路从单线升到BGP，价格基本是跳着走的——所以先搞清楚你的用户在哪个网，再谈带宽大小。

## 防御要不要和带宽一起买

如果业务有过被DDoS打停的历史，防御要在选带宽时就一起规划，事后加购往往更被动。

从报价看，防御在这个市场已经不算奢侈品：499元/月的100M整机自带50G防御；镇江BGP机房另设高防区，集群防御标称1T、单机200G~240G。相比之下，按年计费的纯独享带宽，公开报价里没有防御项，需要单独确认，被打了要么硬扛，要么临时加钱。

真正要问清的不是防御数字有多大，而是三件事：攻击超过防御上限后机房怎么处理、清洗流量是否额外计费、会不会封IP。这几个问题的答案，不同机房之间能差出一台服务器的钱。

## 大带宽租用常见问题

**100M大带宽够用吗？**
按业务算，不按感觉算。100Mbps理论上限约12.5MB/s：下载站按人均占1~2Mbps算，能同时撑住50~100个满速用户；视频串流按人均3~5Mbps算，大约20~30路并发。不够再升级，带宽加钱就能补，先选对线路更重要。

**月付和年付怎么选？**
先月付。先用月付验证线路质量和保底带宽，跑稳定了再谈年付锁价，顺序别反。

**大带宽一定要配高防吗？**
被打过就配，没被打过可以先观察。50G防御的整机月付并不比裸带宽方案贵多少，防御本身不是大头，关键是确认被打超量后的处理规则。

**海外大带宽和国内有什么区别？**
计费方式和线路都不同。以多线通10Gbps方案为代表，海外按端口速率收固定费、不限流量；国内按带宽计费。海外节点如果还要服务大陆用户，回程线路质量直接决定晚高峰的体验，这点要在测试IP阶段验证。
